# Fornax How-to Notebooks

[Fornax Documentation](xref:fornax-docs) | [Science Console](https://science-console.fornax.sciencecloud.nasa.gov/) | [Science Showcase Notebooks](https://nasa-fornax.github.io/fornax-demo-notebooks/) | [Community Forum](https://discourse.fornax.sciencecloud.nasa.gov/)

This collection houses hands-on, “how-to” notebooks for working effectively on the Fornax Science Console.
Tutorials in this repo focus on topics common to many Fornax users.
These tutorials are designed for scientists.
They emphasize reliable, reproducible patterns and performance-aware practices.
For examples of how to do science workflows starting with an idea, working through the project, ending with a reproducible plot, see [Fornax Science Showcase Notebooks](https://nasa-fornax.github.io/fornax-demo-notebooks/).

The notebooks and their run-time dependencies are also available pre-installed on the Fornax Science Console.
For more information, consult the [](xref:fornax-docs/notebook-tutorials#notebooks-in-fornax) section of the documentation.

These notebooks are written and maintained using the MyST Markdown format, more details and references about it can be found in the [](xref:fornax-docs#working-with-markdown) documentation section.
